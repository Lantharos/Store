# schelf.store

Lantharos's distribution service and app store. Developers publish releases from their own GitHub Actions with trusted publishing, or upload them; Schelf checks them, a person reviews them where it's called for, and signs them. People get the apps from download pages and stable links on any system, through the apps' own updaters, and through the Schelf app on Luft. Projects don't have to be listed in the store to host their releases here.

The design is in [docs/design.md](docs/design.md), with the details split across the other files in [docs/](docs/).
