# schelf.store

Lantharos's distribution service and app store. Developers connect a GitHub repository; every release is built in their own GitHub Actions, published with trusted publishing, reviewed by a person in Pult and signed. People get the apps from download pages on any system, through the apps' own updates on Windows and macOS, and through the Schelf app on Luft.

The design is in [docs/design.md](docs/design.md), with the details split across the other files in [docs/](docs/).
